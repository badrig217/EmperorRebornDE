============================================================
  DEUTSCH
============================================================

WAS DU BRAUCHST
---------------
- Windows 10 oder 11 (64 Bit)
- Dein eigenes Spiel: die 4 Original-CDs (deutsch oder englisch)
  oder ISO-Abbilder davon. Das Spiel ist NICHT enthalten.
- Den offiziellen Patch 1.09: EM109DE.EXE (deutsch) oder
  EM109EN.EXE (englisch). Er ist urheberrechtlich geschuetzt und
  deshalb nicht enthalten (frueher kostenloser Download, heute
  z. B. auf Fan-Seiten wie CNCNZ zu finden).

INSTALLATION
------------
1. Diese ZIP in einen eigenen Ordner entpacken, z. B.
       D:\Spiele\EmperorSpice
   WICHTIG: keine Umlaute oder Sonderzeichen im Pfad.

2. EM109DE.EXE (oder EM109EN.EXE) in denselben Ordner legen:
       D:\Spiele\EmperorSpice\
           EmperorSpice.exe
           EmperorHooks.dll
           EM109DE.EXE        <- selbst dazulegen
           graphics\          <- Grafik-Paket

3. EmperorSpice.exe starten und "Spiel jetzt hier installieren?"
   mit OK bestaetigen.

4. Installationsquelle waehlen:
   Ja   = von den CDs: CD 1 einlegen, die weiteren CDs werden
          nacheinander abgefragt (CD-Namen EMPEROR1 - EMPEROR4).
   Nein = aus ISO-Dateien: die 4 ISO-Dateien auswaehlen (mit
          Strg mehrere markieren). Die Reihenfolge ist egal.
   Blaue Meldung "Der Computer wurde durch Windows geschuetzt"?
   -> "Weitere Informationen" -> "Trotzdem ausfuehren".
   (Das Programm ist nicht kostenpflichtig digital signiert.)

5. Fertig. Auf dem Desktop liegt die Verknuepfung
   "Emperor Spice". Aufloesung waehlen, "Spielen" klicken.
   Die CDs werden danach nicht mehr gebraucht.

GRAFIK-PAKET (dgVoodoo2 + ReShade)
----------------------------------
- Im Launcher ein-/ausschaltbar ("Grafik-Paket").
- Im Spiel:  Rollen-Taste = Effekte ein/aus
             Pos1         = ReShade-Menue (Schaerfe, Kontrast ...)
- In dgVoodoo KEINE Kantenglaettung (MSAA) einschalten - das
  Spiel haengt sonst. Kantenglaettung macht ReShade (SMAA).

PROBLEME
--------
- Protokoll: data\emperor.txt - bei Fragen bitte mitschicken:
  https://github.com/badrig217/EmperorSpice/issues
- Kleine Schrift im Spiel: Aufloesung "Hochskaliert ..., grosse UI".
- Warnung "Falsche Game.exe-Version": "Nein" waehlen, dann wird
  neu installiert.


============================================================
  ENGLISH
============================================================

YOU NEED
--------
- Windows 10 or 11 (64-bit)
- Your own game: the 4 original CDs (English or German) or ISO
  images. The game is NOT included.
- The official v1.09 patch: EM109EN.EXE or EM109DE.EXE
  (copyrighted, not included; still found on fan sites like CNCNZ).

INSTALL
-------
1. Extract this zip to its own folder, e.g. D:\Games\EmperorSpice
   (no special characters in the path).
2. Put EM109EN.EXE (or EM109DE.EXE) next to EmperorSpice.exe.
3. Run EmperorSpice.exe and confirm the installation.
4. Choose the source: Yes = CDs (insert disc 1),
   No = select the 4 ISO files (any order).
   Windows SmartScreen? -> "More info" -> "Run anyway".
5. Done. Use the "Emperor Spice" desktop shortcut, pick a
   resolution and click "Play". The CDs are no longer needed.

GRAPHICS PACK
-------------
- Toggle it in the launcher ("Graphics pack").
- In game: Scroll Lock = effects on/off, Home = ReShade menu.
- Do NOT enable MSAA in dgVoodoo (the game hangs); ReShade SMAA
  does the anti-aliasing.

PROBLEMS
--------
- Log file: data\emperor.txt - attach it to an issue:
  https://github.com/badrig217/EmperorSpice/issues
